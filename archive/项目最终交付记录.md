## 4. 故障应急与回滚准备

若上线后出现异常状况，按以下步骤快速处置：

1. **快速恢复主域名可访问性**：
    Vercel 回滚目标和 Deployment ID 需在发布平台重新核实后填写，本地证据不沿用历史编号。
2. **飞书接口降级预案**：
   若飞书 API 出现大规模服务中断，在 Vercel 项目环境变量中临时删除 `FEISHU_APP_SECRET`，系统将安全回退至快照只读模式（`mode=snapshot`），确保简历访问链接不受影响。
3. **代码级别回滚**：
   使用标准修复提交推进，禁止使用 `git reset --hard` 破坏版本历史。
