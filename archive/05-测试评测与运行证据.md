# 模块 05：测试评测与运行证据

## 任务目标

把项目从“能演示”提升为“可复现、可解释、可在简历中举证”，并确认简历中的数字没有超过真实能力。

## 测试范围

### 1. 确定性规则

覆盖：

- 价格低于 89 元。
- 价格等于 89 元。
- 投放日期早于活动开始。
- 投放日期晚于活动结束。
- 不支持的画布比例。
- 禁用词直接命中。
- 禁用词变体。
- 修改产品外观要求。
- 缺失必要字段。
- 合规任务。

### 2. DeepSeek 语义复核

使用 Mock 测试：

- `PASSED`
- `BLOCKED`
- `REVIEW_REQUIRED`
- 非法 JSON
- 超时
- HTTP 错误
- 未配置 API Key

使用一次真实 DeepSeek 冒烟测试：

```text
行业标杆级保温体验
```

预期被语义复核阻断。真实冒烟测试不得写飞书。

### 3. 飞书适配

覆盖：

- 字段映射。
- 单值和附件值解析。
- 输入指纹。
- 未变化任务跳过。
- 通过任务上传附件。
- 阻断任务不上传附件。
- 写回字段与输入字段分离。
- 每次最多 3 条待处理任务。

### 4. 线上接口安全

覆盖：

- 无口令写请求返回 401。
- 错误口令返回 401。
- 正确口令允许执行。
- 请求体超过 8KB 被拒绝。
- 非固定任务 ID 被拒绝。
- 同任务并发执行被拒绝。
- 图片代理只允许固定 Base 已登记的附件 Token。
- 公开 GET 不返回敏感变量。

### 5. 前端

覆盖：

- 所有关键 ID 存在。
- 案例切换可用。
- 实时和快照模式展示正确。
- JSON 复制可用。
- 图片地址带版本参数。
- 阻断任务不出现下载按钮。
- 管理员口令不写入本地存储。

## 指标口径

- 任务判断准确率：预测任务状态与独立真值一致的任务数 / 总任务数。
- 异常任务检出率：正确拦截的异常任务数 / 异常任务总数。
- 规则码一致率：预测规则码与真值规则码一致的任务数 / 总任务数。
- 单图端到端耗时：从提交一条合规任务到图片和飞书回写完成。

不要把 10 条小样本的结果描述成通用模型准确率。

## 运行证据文档

在 `第五天作业` 新建一份《端到端运行与评测证据.md》，至少包含：

1. 测试时间和提交 SHA。
2. 流水线版本和规则版本。
3. 测试数量与通过数量。
4. 10 条评测集的构成。
5. 6 条异常类型。
6. 真实 DeepSeek 冒烟测试输入和结论。
7. 飞书端到端任务 ID。
8. 端到端耗时。
9. 幂等验证结果。
10. 已知限制。

不得包含任何密钥、管理员口令、完整访问令牌。

## 验收标准

- 所有自动化测试通过。
- 评测仍为 10/10、6/6、10/10，或如实更新新结果。
- 有一条真实 DeepSeek 证据。
- 有一条真实飞书端到端证据。
- 指标定义可复现。
- 失败或限制被如实记录。
