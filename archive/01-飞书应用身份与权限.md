让项目使用飞书应用机器人身份读取固定演示 Base，并具备更新任务字段、上传图片附件和读取已回写图片的最小权限。

本模块只处理飞书应用身份和权限，不修改前端，不部署 Vercel，不执行真实营销任务。

## 必须先做的只读检查

1. 在项目根目录执行：

```powershell
lark-cli.cmd auth status
lark-cli.cmd config --help
```

2. 检查当前应用权限列表和版本发布状态。
3. 检查固定 Base 是否已经把该应用添加为文档应用或协作者。
4. 不要输出、记录或截图任何完整密钥。

## App Secret 处理规则

优先寻找不重置密钥的合法配置方式，例如用户已经保存在密码管理器或安全环境中的 Secret。

如果飞书后台仍然只有“重置 App Secret”：

1. 立即暂停。
2. 向用户明确说明：
   - 将重置的是 `cli_aae2a8cf21239be2` 的 App Secret。
   - 旧 Secret 会立即失效。
   - 当前项目没有可用机器人身份，因此重置对现有线上链路没有可观察影响，但可能影响用户在别处使用同一应用的脚本。
3. 只有用户回复“确认重置飞书 App Secret”后才可执行。

重置后：

- 只通过安全输入把 Secret 配置给 `lark-cli`。
- 不在终端回显 Secret。
- 不写入仓库文件。
- 不把 Secret 放入任务总结。

## 最小权限范围

以实际 OpenAPI 报错和飞书官方权限说明为准，只增加本项目需要的权限：

1. 读取 Base 记录。
2. 更新 Base 记录。
3. 读取 Base 字段和表结构，如适配器运行确实需要。
4. 上传图片到 `bitable_file`。
5. 下载或读取该应用已上传、且属于固定演示 Base 的图片附件。

不要添加通讯录、消息、日历、审批等与本项目无关的权限。

权限变更后，如飞书要求发布新应用版本，创建最小版本并发布；记录版本号，但不要修改应用名称或所有者。

```powershell

  --table-id tblSjaJQZyyf1WR4 `
```

## 验收标准

- `lark-cli auth status` 显示 bot 可用。
- bot 能读取商品表和任务表。
- `python main.py --feishu --dry-run` 成功。
- Base 中没有任何记录被试运行改写。
- 没有密钥出现在 `git status`、`git diff` 或已跟踪文件中。
- 权限列表只包含项目所需的 Base 和图片附件能力。

## 停止条件

出现以下任一情况立即停止：

- 需要重置 Secret 但用户尚未明确确认。
- 飞书要求组织管理员审批权限。
- 应用不属于当前用户或当前组织。
- Base 未授权给应用且无法由当前用户添加。
- 任意密钥出现在终端输出、Git 差异或日志文件中。
