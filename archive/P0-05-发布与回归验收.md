# P0 模块 05：发布与回归验收

## 一、模块目标

将 P0 前端和证据改进发布到现有 Vercel 项目，确认飞书实时链路没有回归，并准备可立即使用的回滚版本。

## 二、发布范围

本轮允许发布：

- 面试官体验路径改进。
- 运行证据摘要。
- 前端相关测试。
- 公开证据数据。
- 必要的文档和文件结构整理。

飞书 PRD 是外部文档，不依赖代码发布。

## 三、发布前检查

### 1. 工作区

```powershell
git status -sb
git diff --check
```

确认没有不相关修改。

### 2. 密钥

确认以下内容未进入 Git：

- `.env`
- `.env.local`
- `.vercel`
- `FEISHU_APP_SECRET`
- `DEEPSEEK_API_KEY`
- `DEMO_ADMIN_TOKEN`
- Vercel 或飞书访问令牌。

### 3. 测试

```powershell
python -m unittest discover `
  -s .agents/skills/simple-visual-compliance/tests `
  -p "test_*.py"
```

本模块不要求重新执行真实飞书端到端任务，但必须确保已有自动化测试全部通过。

### 4. 本地构建

```powershell
$env:UV_CACHE_DIR = Join-Path $env:TEMP 'cha-cup-uv-cache'
npx.cmd --yes vercel pull --yes --environment production
npx.cmd --yes vercel build --prod
```

## 四、提交策略

建议按模块形成清晰提交：

1. `feat: improve recruiter demo journey`
2. `feat: add public delivery evidence`
3. `docs: align project prd and day-five outputs`

如果实际改动很小，可以合并为一个提交，但提交说明必须准确。

只推送到：

```text
https://github.com/Tian-Timm/ecom-marketing-agent
```

不要推送到其他远程仓库或 Sites 项目。

## 五、生产发布

使用现有 Vercel 项目：

```powershell
npx.cmd --yes vercel deploy --prebuilt --prod --yes
```

必须确认：

```text
Aliased https://cha-cup-marketing-demo.vercel.app
```

不得用新的随机域名替换简历中的原链接。

## 六、线上回归清单

### 页面基础

- 首页 HTTP 200。
- 标题和工作区正常。
- 数据来源显示飞书实时读取。
- DeepSeek 状态正常。
- 四个案例可以切换。
- 默认显示合规案例。

### 访客路径

- 不输入管理员口令也能查看案例。
- 合规案例显示图片。
- 价格违规显示原因且无下载按钮。
- 文案违规显示原因且无下载按钮。
- 证据摘要数字正确。
- 样本口径说明存在。

### 原有功能

- 刷新任务可用。
- 实时任务列表可读。
- JSON 可以展开。
- JSON 可以复制。
- 图片可以下载。
- 管理员口令弹窗只在主动执行时出现。

### 接口

- `/api/status` 返回 `online=true`、`mode=live`。
- `/api/tasks` 返回飞书任务。
- `/api/run` 无口令返回 401。
- `/api/run` 错口令返回 401。
- 不测试或公开正确管理员口令。

### 响应式

- 1440×900。
- 1920×1080。
- 390×844。
- 无文字溢出。
- 无固定舞台缩放。

## 七、回滚准备

发布前记录：

- 证据所属阶段起始 Git SHA：`707190f`
- Vercel Deployment：本阶段未重新验证，不使用历史编号作为当前证据

如果新版本出现 P0 故障：

1. 在 Vercel 将稳定 Deployment 重新提升为 Production。
2. 保留失败 Deployment 用于排查。
3. 使用新的修复提交，不执行 `git reset --hard`。
4. 如果只是飞书异常，允许回退到快照模式保证页面可访问。

## 八、P0 故障定义

出现以下任一情况立即回滚：

- 原域名无法访问。
- 页面没有任务数据。
- 所有生成图片加载失败。
- 案例切换失效。
- 页面公开了敏感信息。
- 写接口无口令可以调用。
- 前端错误地显示实时能力。

## 九、验收标准

- 原 Vercel 域名保持不变。
- 面试官体验路径完整。
- 运行证据正确显示。
- 飞书 live 模式保持正常。
- 鉴权没有回归。
- 自动化测试全部通过。
- 桌面和手机检查通过。
- 稳定版本和回滚方式已记录。
