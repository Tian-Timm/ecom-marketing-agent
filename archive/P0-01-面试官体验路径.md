# P0 模块 01：面试官体验路径

## 一、模块目标

让第一次打开 Demo 的访客在不阅读 PRD、不输入管理员口令的情况下，完成一条清晰的体验路径：

```text
认识任务输入
→ 查看合规任务出图
→ 查看价格违规阻断
→ 查看语义违规阻断
→ 理解系统与飞书实时连接
```

目标完成时间不超过 60 秒。

## 二、现有问题

1. 页面是完整运营工作台，但访客不知道应该先点击哪里。
2. “快速体验审查案例”已有案例按钮，但缺少推荐顺序。
3. 输入、审查结果和图片分布在三栏，第一次进入时认知成本较高。
4. 管理员操作与访客浏览同时存在，容易让访客误以为必须获得口令才能体验。
5. 处理记录和 JSON 对面试官有价值，但优先级不应高于结果本身。

## 三、推荐体验路径

### 第一步：默认展示合规任务

页面加载后继续默认选中 `MKT-001` 或当前稳定合规案例。

访客应立即看到：

- 输入文案。
- 活动价格。
- “审查通过”状态。
- 已生成营销图片。

不要要求访客先点击“执行”。

### 第二步：推荐查看价格风险

在案例按钮中为“价格低于底线”增加弱引导，例如：

```text
② 看价格拦截
```

点击后直接切换已有结果，不触发线上写操作。

访客应看到：

- 活动价。
- 最低允许价格。
- 明确的阻断原因。
- 不显示图片下载按钮。

### 第三步：推荐查看语义风险

将“广告违禁词”作为第三个推荐案例。

访客应看到：

- 命中的问题文案。
- 简洁的语义或规则结论。
- 任务在出图前被阻断。

### 第四步：查看真实数据来源

页面的数据来源区域应明确显示：

- 飞书多维表格。
- 实时读取。
- DeepSeek 已启用。
- 最近更新时间。

不要把数据源状态写成大段技术介绍。

## 四、页面改进方案

### 1. 案例区增加顺序感

保留现有案例卡片，在卡片标题中使用轻量编号：

- ① 合规出图
- ② 价格拦截
- ③ 文案拦截
- ④ 外观修改

编号只承担引导作用，不增加时间轴或复杂步骤条。

### 2. 增加一句访客提示

建议文案：

```text
依次选择案例，查看同一套流程如何放行合规任务并阻断业务风险。
```

只保留一句，不增加架构说明。

### 3. 强化当前选中案例

当前案例使用：

- 绿色细边框。
- 浅绿色背景。
- 清晰的结果 Badge。

未选中案例不使用阴影或强色彩。

### 4. 调整结果区信息顺序

合规任务：

```text
状态结论
→ 生成图片
→ DeepSeek 摘要
→ 处理记录
→ JSON
```

违规任务：

```text
状态结论
→ 具体修改原因
→ DeepSeek 或规则证据
→ 处理记录
→ JSON
```

### 5. 区分访客操作和管理员操作

- 案例浏览始终公开可用。
- 实时执行按钮只在服务端写能力可用时启用。
- 页面不要主动弹出管理员口令。
- 只有访客主动点击执行时才打开口令弹窗。
- 在执行按钮附近使用简短提示“实时执行需要管理员口令”。
- 不解释口令的服务端实现。

## 五、修改范围

主要文件：

- `index.html`
- `.agents/skills/simple-visual-compliance/tests/test_frontend_demo.py`

如非必要，不修改：

- 业务规则。
- DeepSeek Prompt。
- 飞书 OpenAPI 适配器。
- Python 图片组装。
- API 鉴权。

## 六、必须保留的 DOM 和功能

- `demo-case-list`
- 所有 `[data-demo-task]`
- `task-list`
- `task-form`
- `run-button`
- `refresh-button`
- `sync-button`
- `result-content`
- `admin-dialog`
- JSON 展开和复制。
- 图片下载。
- 当前选中任务状态。

不得通过重新制作静态页面替换现有交互。

## 七、响应式要求

### 桌面

- 案例按钮保持一行或整齐网格。
- 三栏工作区仍是视觉主体。
- 新引导内容最多占用一个紧凑横条。

### 手机

- 案例按钮允许两列或横向滚动。
- 点击案例后滚动到结果区。
- 不出现固定宽度舞台缩放。
- 按钮文字和 Badge 不溢出。

## 八、测试方案

1. 初次加载默认显示合规案例。
2. 依次点击四个案例，输入与结果同步切换。
3. 违规案例没有下载按钮。
4. 浏览案例不会调用写接口。
5. 管理员弹窗不会自动出现。
6. 点击实时执行后才请求管理员口令。
7. 刷新后仍能读取飞书任务。
8. 运行前端自动化测试。
9. 检查浏览器控制台无错误。

## 九、验收标准

- 10 秒内看懂这是营销图审查与生成工作台。
- 60 秒内完成合规、价格违规和文案违规三个案例。
- 不需要管理员口令即可完成访客体验。
- 页面没有新增面向用户的内部技术说明。
- 原有实时执行、刷新、同步、JSON 和下载功能保持可用。
- 桌面和手机均无文字溢出。

## 十、停止条件

出现以下情况立即停止：

- 需要删除现有关键 DOM 标识。
- 必须改变后端返回结构才能完成视觉调整。
- 案例切换会触发真实写操作。
- 修改导致原 Vercel 页面无法加载历史图片。
